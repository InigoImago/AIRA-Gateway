When a model cannot answer A request whose model cannot answer — an outage, a quota, a model its provider retired — gets that error, unless a chain names models to try instead. The chains here are the installation's, one for each kind of request. A use case follows them unless its pipeline keeps a chain of its own for text generation or chooses no fallback at all, and every model in a chain is used only where the use case has it released: a chain here is not a release. The answer names the model that gave it, and so does the request's row.
