Models & prices

What each model costs per 1,000,000 tokens, in US dollars — every provider on this gateway prices in dollars, so that is the one currency in which these figures need no conversion nobody performed. Input and output are priced separately because every provider bills the two differently. Cost budgets are calculated from these figures; a model without a price still works, but its consumption cannot be costed.
