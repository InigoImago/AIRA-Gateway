When a model cannot answer

A model that cannot answer — an outage, a quota, a model its provider retired — is replaced by the models listed here for its kind of request, tried in the order they are listed. A kind with none listed has no fallback: the caller gets the error.

Every model is still held to this use case's release and to what the request asks of it — one that cannot answer it is passed over by name — and the answer, like the request's record, names the model that gave it.
