A key is issued for one use case and carries it, so a client normally sends nothing else — no use case in the URL, no header. The use case comes from the key, not from the address. A caller who belongs to several names one with the X-AIRA-Use-Case header or the /uc/<slug> path — which chooses among what they already have and never grants anything: naming another use case answers 403.
