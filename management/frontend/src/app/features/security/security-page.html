Stopped traffic An immediate, manual refusal — the kill switch of FRD-503. It reaches one caller (a username or service account), one API key (by its prefix), or one whole use case. There is no switch for the installation: everything here is scoped, on purpose. Stopped requests are answered 429 — the credential is still valid, they are being told to come back later — and each is recorded with the outcome suspended, so an investigation afterwards can see exactly what was refused. It takes a few seconds to reach every gateway instance, and lifting one takes the same.
